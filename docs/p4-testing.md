# P4 v2：整小时、备注与尾段验收

当前阶段：P4 开发交付，等待用户验收；P5 未开始。

## 已确认规则
- 用户确认真实睡眠、锁屏测试通过；自然跨午夜暂不具备实测条件，继续标注未实测，不据此宣称已通过。
- 用户说明旧记录均为测试数据，无需保留到新版。P4 从空白库开始，默认目录 `~/Library/Application Support/StudyTimerP4`；旧 P3 目录不导入，也不改写。
- 手动停止而未选择尾段处理方式时先保存待处理。随后正常退出，会自动合并到同段上一条；没有上一条则单独保存，并保留文字。

## 打开与两种模式
先退出旧版本及正在运行的 P4，避免同时显示多个悬浮窗。

**日常使用：**双击 `StudyTimer.app`，采用真实时间和正式 P4 数据库，不自动开始计时。退出请用鼠标点击“…”或菜单栏中的“退出”，没有退出快捷键。右上角记录图标查看历史，“…”和菜单栏控制计时。

**快速验收：**双击同目录的 `开始独立验收.command`。它会通过终端启动同一个应用，使用全新的测试目录；初始模拟时间为此刻真实时间，主窗显示“模拟时间 HH:MM · 快进计入测试时长”。菜单额外提供推进 1/30/60/180 分钟和模拟持续学习至次日 00:20；跨日操作先显示新增时长，确认后才推进。该模式不改系统时间，也不写正式库。

退出后若要验证持久保存，双击 `继续上次验收.command`。仍使用上次测试目录及当前时间/保存点中较晚的时刻，不会回拨测试时间。再次运行“开始独立验收”会建立新目录；旧测试目录仍保留，不自动删除。

源码目录也可用 `bash scripts/open-p4-acceptance.sh` 启动一次新验收，终端会打印独立数据路径。上述 .command 入口位于交付目录/应用包中。

## 建议测试顺序
| 编号 | 操作 | 预期 |
|---|---|---|
| P4-01 | 独立验收中开始，菜单推进 60 分钟 | 星光开始时闪烁 3 次，总计停留 30 秒；备注卡片在计时窗上方；计时继续 |
| P4-02 | 将主窗拖到屏幕顶端，再触发卡片，收起 | 主窗临时下移，卡片仍在上方；收起恢复原位 |
| P4-03 | 卡片打开期间主动拖动主窗，再收起 | 保留新位置；只点击不拖动则仍可恢复原位 |
| P4-04 | 卡片填写中文、选择候选词、换行，等待约半秒 | 文本可编辑并自动保存；计时不中断，不抢其他应用的输入焦点 |
| P4-05 | 保持当前卡片，输入草稿；菜单再推进 60 分钟 | 当前草稿和条目不被替换；提示有新记录，关闭当前卡片后再显示新提醒 |
| P4-06 | 选择稍后填写，打开历史页，点铅笔补填/修改/清空 | 修改可见且持久保存；时长不能编辑 |
| P4-07 | 新一次验收中开始→推进 60 分钟→收起→推进 30 分钟→停止 | 出现尾段，可选择单独记录或合并上一条；文字保存，合并不增加日总时长 |
| P4-08 | 合并上述尾段，再开始 30 分钟 | 当日累计约 2 小时；两个学习段独立，第二个整小时提醒只出现一次 |
| P4-09 | 新一次验收开始，只推进 30 分钟后停止 | 没有同段上一条，合并按钮禁用；可单独记录或稍后处理 |
| P4-10 | 填写尾段但先不选择，正常退出；继续上次验收 | 退出时自动合并同段上一条；没有上一条单独保存，备注不丢失 |
| P4-11 | 计时中隐藏窗口，推进 180 分钟，再显示 | 合并为一个提醒卡片批次，使用上一条/下一条填写，各整小时条目都保留 |
| P4-12 | 计时中推进到次日 00:20 | 昨日归档，新日继续；昨日尾段自动并入同段上一条，没有上一条则新建 |
| P4-13 | 暂停后推进到次日 00:20 | 暂停时间不计入，跨日不自动开始 |
| P4-14 | 完成提醒、正常退出并继续上次验收 | 记录、备注与已展示标记保留，不重复弹已展示的整小时提醒 |
| P4-15 | 切换浅色/深色，打开多条记录和多行备注 | 文字清楚，中文时长与钟点可区分，长备注不会被旧缓存或单行布局遮住 |

验收模式每秒也会前进一秒，所以通过菜单推进后的总时长可能多出操作期间的几秒，这是正常的。精确 25＋35、90＋30、跨日边界由隔离自动化报告核对。

## 保存与失败处理
备注修改后约 0.4 秒自动保存，保存/收起/退出时立即提交。保存失败明确显示错误，保留尚未落盘的输入，不伪报成功；可从菜单重试。失败注入测试位于隔离自动化中，不建议破坏正式数据库或文件权限来测试。

小时阈值和唯一编号与计时状态在同一 SQLite 事务保存。提醒标记也持久化；批次展示后即标记已展示，稍后填写的内容从历史补填。若标记写入失败则不消费提醒。

卡片在输入时，新提醒等待；历史编辑窗口打开时也等待。正常退出先保存草稿，再处理所有尚未选择的尾段。异常关闭只恢复已保存内容，尚未完成的自动保存可能丢失，已保存记录不会被关闭间隔补算。

## 验证边界与反馈
v2 的针对性回归与验证边界见 p4-v2-self-test.md。新一轮真实锁屏/睡眠、中文输入法完整候选交互、不同桌面与全屏体验建议在本版再回归一次。自然跨午夜仍未实测；快进跨日是隔离模拟。

请反馈测试编号、操作和实际表现。P4 通过并明确允许继续后，才进入 P5。

## 本次反馈的重点复测
1. 日常计时直接双击 v2 `StudyTimer.app`。点击开始，记录页应显示本次实际开始钟点，无固定 09:00。
2. 独立验收从当前真实时刻出发；点击推进会增加模拟学习时长。运行中模拟跨日会把直到目标的时间全部算入，这是持续学习模拟。若不希望增加时长，先暂停再跨日。
3. 先停止保存一段，再开始第二段并模拟跨日，前一段的开始时间、时长、备注应保持不变，日总计只增加第二段午夜前的部分。
4. 特效出现后观察最初 3 次柔和明暗变化，随后保持，30 秒消失；卡片不会因此关闭。
5. 两处退出菜单均无快捷键标记，鼠标点击退出后悬浮窗和菜单栏图标消失。悬浮窗不抢焦点，其他应用在前台时键盘仍归该应用，不使用 Command-Q 退出悬浮窗。

v1 的固定 09:00 记录属于旧独立验收库。v2 保留旧文件，不将这些模拟数据转换成真实学习记录，也不据模拟数据重写正式库。
