# 学习计时 1.1 使用说明

适用于本次交付的 Apple Silicon Mac 版本。应用在本地运行，无需账号或网络。

## 打开与升级
1. 如果旧版仍在运行，先点击它的“…”菜单或菜单栏计时图标，选择“退出”。
2. 解压应用包，双击 `StudyTimer.app`。也可将应用复制到“应用程序”文件夹再打开。
3. 启动后默认不计时，点击“开始学习”。学习段从点击开始时的实际时间记录。

当前版本继续读取 P4 已保存的记录与窗口位置。无需导入，不要删除旧数据目录。正式应用没有模拟快进菜单，也不附带验收启动器；旧的 `.command` 验收入口不适用于本版本。

## 日常操作
- **开始学习**：创建一个新学习段，当日总计保留。
- **暂停 / 继续**：暂停期间不累计，继续仍属于当前段。
- **停止学习**：结束当前段；有尾段时，可单独记录或合并到本段上一条。没有上一条时只能单独保存。
- **拖动**：可从四边、数字或非按钮空白处拖动。右上角记录和“…”按钮均可点击周围空白。
- **学习记录**：点击右上角记录图标，按日期查看各学习段、时长及备注。铅笔可补填、修改或清空文字，时长不能手动修改。
- **隐藏 / 恢复**：菜单中隐藏计时窗，计时仍继续；点击菜单栏计时图标选择“显示计时窗”找回。
- **退出**：用鼠标点击“退出”。没有退出快捷键。悬浮窗不抢键盘焦点，在其他应用前台按 Command-Q 会交给那个应用。

深浅色自动跟随系统。关闭历史窗口不会退出计时器。

## 鼓励与内容记录
每日累计每满一小时，出现无声星光：开始柔和闪烁 3 次，总计停留 30 秒。备注卡片位于整个计时窗上方，计时继续，不会自动抢输入焦点；主动点击输入区后填写。

屏幕顶端空间不足时，计时窗临时下移；关闭卡片后恢复。若卡片期间主动拖动，则保留新位置。星光结束不会自动关闭备注。

备注约 0.4 秒自动保存，保存、收起和退出会立即提交。可选择稍后填写，再到历史中编辑。新提醒不会覆盖正在输入的草稿，漏过多个小时会合并展示，但各条记录保留。

尾段暂不选择时先保存为待处理；正常退出时自动合并到同段上一条，没有上一条则单独保存。合并保留文字，不重复增加累计。

## 清理碎片记录
在“学习记录”中，点击学习段标题旁的垃圾桶可删除整个学习段；点击某条内容旁的垃圾桶只删除该条。确认后会连同备注删除，并扣除对应有效时长；取消不会改变记录或计时状态。

删除当天记录时，如果正在学习，确认删除后会暂停，可点击“继续学习”。如果删除整个当前段，或条目删完后已经没有有效时间，继续时会创建新段。删除其他日期的记录不会暂停当前学习。

删除后悬浮窗与当日累计立即更新，并按新累计的下一个整小时提醒。例如从2小时35分钟删到1小时35分钟，再学25分钟会再次出现2小时提醒。删除本身不弹鼓励卡片；该日期已打开的卡片会在草稿保存后收起，未删除的文字保留。

删除不可撤销。保存失败时原记录和计时状态保持，可重试；如需保留原始记录，可按下方说明先备份。

## 时间与恢复
内部按北京时间零点分日，界面不显示时区标签。运行中跨零点会归档昨日，自动继续新一天；暂停或停止跨零点不会自动开始。

锁屏、睡眠时运行中的时间继续累计，恢复后补算。正常退出先保存并停止；异常关闭只恢复最近成功保存的数据，重新打开需要手动开始，关闭期间不补计。系统清醒且运行时，每 5 秒保存检查点；睡眠期间不能持续落盘。

## 数据与备份
正式数据目录为 `~/Library/Application Support/StudyTimerP4`。名称保留是为了兼容已有记录。主库是 `study.sqlite3`，应用运行时可能有同名 `-wal` / `-shm` 辅助文件。

手动备份前先正常退出计时器，然后复制整个数据目录到另一位置。恢复备份时也应先退出，并先保留当前目录的副本，再替换为完整备份。不要只拷贝运行中的数据库单文件，也不要直接编辑数据库中的时间。

菜单“查看保存状态”可以查看最近保存时间和数据目录。若出现失败提示，使用“重试保存/读取”；不要通过删除数据库排障。读取损坏或未知版本时应用会保留原文件，不静默清空。

## 已知限制
本次仅在当前 Apple Silicon Mac 验证；最低部署目标 macOS 13，不代表所有系统版本均已实测。应用采用本地 ad-hoc 签名，未做 Developer ID 公证，不保证在其他 Mac 上可直接打开。

自然跨午夜仍未实测；分日自动化使用隔离时钟。此前用户已报告真实睡眠与锁屏通过，当前验证没有将模拟检查写成真实跨夜测试。全屏、多桌面及输入法体验请按最终验收单复核。

不包含云同步、Windows、番茄钟、趋势图、导出、开机自启或手动改时长。
