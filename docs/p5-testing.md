# P5 最终验收单

用户已确认 P4 完成并授权 P5。本阶段交付最终 1.0.0 应用、源码、使用说明、回归证据及限制。内部验证通过后，仍等待用户最终验收结论。

先退出旧版，再打开本次 `StudyTimer.app`。真实使用入口只有应用，最终包不含模拟快进启动器。

| 编号 | 操作 | 预期 |
|---|---|---|
| P5-01 | 打开最终应用并查看历史 | 不自动开始；P4 正式记录仍在；菜单没有演示、快进、验收入口 |
| P5-02 | 开始并查看学习段的开始钟点，等待超过 1 分钟 | 使用当前真实钟点，主窗显示 00:01 或已有累计加 1 分钟 |
| P5-03 | 暂停、等待、继续、停止、再次开始 | 暂停不计时；停止形成独立段；重新开始不清空今日累计 |
| P5-04 | 从四边、数字、空白拖动，点击两个右上角图标 | 可拖动；按钮完整点击区正常，不意外拖动 |
| P5-05 | 在浏览器输入，学习累计到整小时 | 上方卡片不夺取输入焦点；星光开始闪烁 3 次、停留 30 秒 |
| P5-06 | 顶端触发卡片并收起；再次触发时主动拖动 | 临时避让后恢复；主动拖动后保留新位置 |
| P5-07 | 输入中文候选词与多行备注，稍后从历史修改/清空 | 不打断计时，草稿不被提醒覆盖，修改正常保存 |
| P5-08 | 停止后分别试单独/合并尾段；未选择直接退出 | 合并不增加总时长；退出按同段合并，无上一条单独保存 |
| P5-09 | 运行中隐藏，再用菜单栏恢复 | 隐藏期间继续计时，窗口能找回 |
| P5-10 | 鼠标点击退出，稍后重新打开 | 窗口与菜单栏图标消失；记录保留，退出期间不累计，不自动开始 |
| P5-11 | 切换系统深浅色、全屏应用和不同桌面 | 外观清楚、悬浮行为符合日常需要，窗口外可正常操作 |
| P5-12 | 运行中锁屏/睡眠再恢复 | 学习时长包含间隔；不重复生成已展示的整小时提醒 |
| P5-13 | 具备条件时，真实运行跨北京时间零点 | 昨日旧学习段保留，新日正确累计；此前仍标注自然午夜未实测 |

精确 25＋35、90＋30、23:40 至 00:20、SQLite 失败、异常退出和重复提醒由隔离自动化覆盖，见 p5-self-test.md；用户不必破坏正式记录或修改电脑时间来验证。

请按编号反馈异常。收到最终通过结论后再记录用户最终验收完成。
