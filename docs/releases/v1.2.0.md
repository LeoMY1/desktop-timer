# v1.2.0 — 学习趋势（macOS 原型版）

下载 `desktop-timer-1.2.0-arm64.zip` 即可取得应用，无需自行编译。

## 1.2 新增
- 学习记录窗口左侧顶部可切换“每日记录”和“学习趋势”，趋势视图左侧显示历史周期列表。
- 支持自然周（周一至周日）和自然月折线图，按应用的 Asia/Shanghai 分日规则汇总每天有效学习时间。
- 悬停查看日期和时长，点击或使用左右方向键选择日期，通过“查看当日记录”进入明细；切换视图和关闭重开窗口后保留浏览位置。
- 今天的累计随计时更新，暂停不计入，删除成功后同步扣减。过去无记录日显示零，未来日期留白且不可选。
- 支持深浅色、最小窗口，以及逐日中文日期和时长的辅助阅读操作。

## 下载与升级
- **设备：Apple Silicon（M 系列芯片）Mac。** 当前不提供 Intel 版本。
- **系统：最低部署目标 macOS 13。** 仅当前 Apple Silicon Mac 验证，未完成所有系统和机型测试。
- 先通过旧版菜单退出，再解压 ZIP，将 `StudyTimer.app` 放入“应用程序”并打开。启动不会自动开始计时。
- 继续使用 `~/Library/Application Support/StudyTimerP4`，bundle ID 与 SQLite schema 保持不变，无需迁移或清空已有记录。
- `SHA256SUMS.txt` 提供应用 ZIP 校验值；GitHub 自动附带的 `Source code` 为对应标签源码。

本版通过 183 项自动化检查：核心与 SQLite 89 项、几何 7 项、真实时间与进程 5 项、AppKit 集成 77 项、发布边界 5 项；另完成隔离合成数据下的原生点击和真实计时检查。发布沿用已验证二进制，并核对安装包完整性及解包签名。测试未访问正式学习数据库。
