# v1.1.0 — macOS 学习计时器（原型版）

无需自行编译，下载下面的 `desktop-timer-1.1.0-arm64.zip` 即可取得应用。

## 下载与打开
- **设备：Apple Silicon（M 系列芯片）Mac。** 当前不提供 Intel 版本。
- **系统：最低部署目标 macOS 13。** 仅当前 Apple Silicon Mac 实测，未完成所有系统或机型验证。
- 解压 ZIP，将 `StudyTimer.app` 拖入“应用程序”，双击打开；首次启动不会自动计时。
- 升级前先从旧版菜单退出；数据仍保存在原来的 `~/Library/Application Support/StudyTimerP4`，无需迁移。
- `SHA256SUMS.txt` 提供应用 ZIP 的 SHA-256 校验值。GitHub 自动附带的 `Source code` 是源码。

## 首次打开与签名
当前为本地 ad-hoc 签名，**尚未完成 Developer ID 签名和 Apple 公证**，不能保证所有 Mac 下载后直接双击启动。

如果系统提示无法验证开发者或 Apple 无法检查应用，请先确认下载来源及完整性，再按系统提示前往“系统设置 → 隐私与安全性 → 仍要打开”。受管理的设备可能无法使用此选项。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 1.1 新增
- 支持删除整个学习段或单条内容记录，扣减对应时长并刷新累计。
- 删除当天记录会暂停运行中的计时，可手动继续；删除其他日期不影响当前计时。
- 删除后按新的累计值重新触发整小时提醒；取消不修改记录，保存失败保留原状态。

## 已有功能
本地悬浮计时、开始/暂停/继续/停止、北京时间分日、整小时无声鼓励、学习内容备注、历史记录与本地 SQLite 保存。无需账号或网络。
