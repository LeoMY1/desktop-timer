## 已修复或受控问题
- 本机仅有 CLT，不依赖 Swift Package 的 PlatformPath 查询；使用直接编译/链接脚本。
- 保存失败不提交候选状态，不伪报暂停或停止成功；后台失败保留内存时长并提供重试。
- 异常恢复不将上次 running 状态延续到当前启动时间。
- 测试入口要求显式隔离目录，缺少时拒绝启动，不会落入正式库。
