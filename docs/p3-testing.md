# P3 v1：真实计时与本地保存验收

P2 已经用户明确验收通过。P3 完成后等待本页测试反馈，P4 尚未授权。

## 打开方式
退出旧 P2 原型，双击项目 `outputs/P3-v1/StudyTimer.app`。也可先解压 `StudyTimer-P3-v1.zip` 再双击其中的应用。应用不显示 Dock 图标，菜单栏计时器图标可找回悬浮窗。

**本版会真实记录学习时间。** 打开时不会自动开始；不足一分钟显示 00:00，满一分钟变为 00:01。右上角记录图标打开真实历史，“…”提供计时、隐藏、保存状态及外观入口。

本阶段交付：开始、暂停/继续、停止、多学习段日累计、固定北京时间分日、锁屏/睡眠时间补算、SQLite 保存、正常退出与异常恢复、真实记录概览。整小时鼓励、内容备注、尾段合并在 P4 接入，因此 P3 停止后直接保存学习段。

## 日常操作验收
| 编号 | 操作 | 预期 |
|---|---|---|
| P3-01 | 打开后先等 10 秒，再开始学习 | 初始不累计；开始后显示“学习中” |
| P3-02 | 开始后等待约 65 秒 | 今日累计增加约 1 分钟，记录页出现学习段 |
| P3-03 | 暂停，等 70 秒，再打开记录 | 累计不增加，状态为暂停 |
| P3-04 | 继续学习约 65 秒，然后停止 | 继续累计，暂停和继续属于同一学习段；停止保留当日累计 |
| P3-05 | 再开始学习约 65 秒并停止 | 新增学习段，同日自动汇总，不清零 |
| P3-06 | 运行中隐藏窗口，等约 65 秒，从菜单栏恢复 | 隐藏期间仍累计 |
| P3-07 | 运行中通过菜单正常退出，等一分钟后重新打开 | 记录保留，退出期间不累计，等待手动开始 |
| P3-08 | 运行中锁屏或让电脑睡眠约 2 分钟，再唤醒 | 运行中的时间包含锁屏/睡眠间隔；暂停状态睡眠则不增加 |
| P3-09 | 自然跨越北京时间零点，或检查隔离测试报告 | 运行状态昨日结束、新日继续；暂停或停止不自动开始 |
| P3-10 | 窗口四边拖动、三个点周围点击、全屏/桌面切换 | 保持 P2 已验收的交互；菜单按钮不会触发拖动 |
| P3-11 | 菜单→查看保存状态 | 显示最近成功保存时间及数据目录；正常运行每 5 秒保存 |

实际睡眠、锁屏和自然跨午夜尚需用户按自身使用场景验证。自动化已覆盖无回调时间跳跃和跨日，不等于电脑已经真实睡眠或整夜运行。

## 异常恢复与隔离测试
默认数据库：`~/Library/Application Support/StudyTimer/study.sqlite3`，请不要删除或手工修改。WAL/SHM 是 SQLite 配套文件。正式数据目录使用独占写入锁，第二实例不能同时写入。

**不要对你的正式记录做强制结束测试。** 交付中附有隔离测试结果；如果需要复现，可从项目根目录依次运行：

```sh
bash scripts/test-p3.sh
bash scripts/test-process-p3.sh
bash scripts/test-ui-p3.sh
```

这些脚本只使用 `work/p3-evidence` 下新建的临时目录；进程测试约 70 秒，会强制终止自己创建的测试进程，不结束桌面上的正式应用，不更改系统时间。

异常关闭只恢复最后成功保存的数据，重新打开后等待手动开始。通常至多丢失距最近 5 秒检查点后的时间；睡眠期间没有持续落盘，若睡眠期间异常断电，损失可能更长。

## 错误与限制
保存失败会在悬浮窗提示，菜单提供重试与错误详情。开始/暂停/停止保存失败时该操作不生效，原计时状态保留；内存里的时间继续按原状态处理。后台保存失败会保留内存累计并尝试再次保存。退出保存失败时可留在应用或明确选择仍然退出。

损坏、缺少必要记录或版本未知的数据库不会被静默覆盖。加载失败时禁止开始计时，修复外部问题后可重试读取。P3 不提供数据修复、导出或同步功能。

仅本机 Apple Silicon / macOS 26.6.2 运行验证，最低构建目标 macOS 13，其他系统版本和多显示器未测。当前本地 ad-hoc 签名，尚未公开发行公证。
