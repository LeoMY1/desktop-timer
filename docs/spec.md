# 技术规格

本文件描述当前可运行原型。历史实现与阶段改动见 stages.md；需求规则以 requirements.md 为准。

## 模块及状态
StudyCore 不依赖 AppKit，负责 TimeSource、TimerEngine、Ledger、SQLiteLedgerStore、StudyController 和提醒选择。StudyTimerApp 负责界面、草稿、窗口、提醒展示与菜单。WindowGeometry 只计算屏幕内位置。

stopped 下开始创建新段；running 下暂停进入 paused；继续沿用该段；停止结束段并回到 stopped。暂停跨午夜关闭旧段，继续时才新建；运行跨午夜归档昨日并自动创建新日段继续。启动或恢复始终停止。

ContinuousClock 与启动日期锚点投影时间，包含系统睡眠；按 Asia/Shanghai 归日。运行推进按午夜与日累计整小时逐一结算。内部保留亚秒精度，只有显示时截取分钟，不能逐小段舍入后累加。

## 数据与持久化
Ledger/SQLite user_version 均为 2。学习段保存有效区间；LearningEntry 保存段内有效秒偏移、备注和尾段待处理标记；HourlyMilestone 保存日期、累计小时编号、关联条目与已展示标记。

日累计从有效区间计算，内容合并不修改这些区间。条目必须连续、不重叠、不超出段时长；结束段需完整覆盖，禁止跨段合并。里程碑按日期和小时编号唯一。

Ledger JSON 快照通过单个 SQLite 事务保存，启用 WAL、FULL 同步、busy timeout；目录锁阻止同库多个写入者。加载校验完整性、版本、引用及区间，损坏或未知数据拒绝加载并保留原文件。

关键操作在候选状态上执行，保存成功后提交界面；失败保留上次状态和错误。运行时每 5 秒保存，阈值与跨日立即保存，睡眠前/唤醒额外检查点。正常退出先保存草稿、结算并停止；异常恢复只关闭最后保存状态，不计算进程关闭期间。

正式目录继续使用 `~/Library/Application Support/StudyTimerP4`，bundle ID 继续使用 `local.study-timer.p4`。路径覆盖只接受绝对路径环境变量 STUDY_TIMER_DATA_DIR。开源整理不迁移或清空数据。

## 提醒、备注与尾段
累计每满一小时为当前段未覆盖的时间建立条目和里程碑，条目可以不足一小时，不跨学习段拼接。漏过多个阈值逐条保存，展示时合为可翻页批次。

卡片打开或历史编辑期间新提醒排队。展示标记成功持久化后才显示；稍后填写可从历史补填。草稿按条目隔离，约 0.4 秒自动保存，收起/保存/退出强制提交；成功后清除缓存，读取最新合并结果。原生 NSTextView 在中文 marked-text 期间不替换组合文本。

手动停止先保存待处理尾段。选择合并将时长并入同段上一条并保留双方文字；没有上一条只能单独保存。午夜或退出自动合并尾段，无上一条则新增。退出还会处理此前手动停止后未选择的尾段，先保存草稿再合并。

## 窗口与动效
主窗 288×176 pt，独立上方备注卡片 288×300 pt。主窗采用非激活 NSPanel、floating、canJoinAllSpaces、fullScreenAuxiliary；按钮不抢焦点，备注点击后才取得输入焦点。

四边、数字和非控件空白可拖动，排除按钮实际范围，右上两图标均为 20×20 pt。上方空间不足临时下移，收起恢复；真正拖动取消自动恢复。显示器变化时校正到可见屏幕。历史窗口可调整尺寸，时长用中文单位与钟点区分。

星光无声，共停留 30 秒，最初 2.4 秒完成三次柔和明暗变化，随后保持。每次带独立标识，旧回调不会关闭新特效。动效结束不收起卡片、不改变计时。

## 构建、测试与公开边界
`bash scripts/build.sh release` 输出日常应用到 outputs/StudyTimer.app；`test` 模式输出 work/build/test 下的内部应用并定义 INTERNAL_TESTING。日常版本不编译模拟操作与 UICheck 执行入口；旧验收参数在访问数据前拒绝。

`bash scripts/test.sh` 重新构建并执行核心、几何、真实进程、内部窗口及发布边界检查，全部使用 work/evidence 下隔离数据。`python3 scripts/package.py` 验证本次报告并打包已构建应用和当前公开源码，不要求个人手工验收证据。源码包遵守 Git 跟踪与忽略规则。

人工记录、自动化报告、用户验收互不替代。历史报告保留其来源与日期，不能表述成当前复测；自然午夜、物理睡眠和其他机型的边界见 validation.md。

## 记录删除（1.1）
RecordDeletion 区分学习段 ID 与内容条目 ID。StudyController 在当前引擎副本上先推进到确认时刻，合入草稿，再执行删除；通过原有 modify/save 路径一次提交。删除目标当天仍运行时只改为 paused，不调用 stop/finishTail。非当天删除仍正常推进当前计时，不改变其状态。

删除条目时，将其有效秒偏移映射到该段的真实 StudyInterval，保留所选区间两侧部分，排除暂停间隔；后续条目的偏移减去已删除秒数，ID、备注和剩余真实区间不变。段原开始/结束事件时间不重写。空段与其内容一起移除；若是活动段则清除 activeSessionID，保留 paused，复用既有 resume 创建新段的路径。

删除后移除该日期大于新累计值的 HourlyMilestone；保留较低阈值但标记已处理，已删除条目的 entryID 清空。由现有 advance 在再次跨越下一个整小时阈值时创建新提醒。Ledger schemaVersion 与 SQLite user_version 均保持 2，不放宽现有记录连续覆盖与时长校验。

历史页通过原生 NSAlert sheet 确认；确认期间提醒暂缓展示，计时仍运行。确认时重新检查日期和目标，跨午夜则按实际日期处理，失效目标报错并保留原状态。事务成功后清理已保存的草稿缓存、受影响日期的卡片以及失效尾段队列，立即刷新菜单和累计。失败不清理草稿，不关闭仍有效卡片。
