# P2 v3：运行与用户验收

交付日期：2026-09-18。请先完成本页测试，再反馈是否通过；收到明确放行前不进入 P3。

## 1. 打开
项目内直接双击 `outputs/P2-v3/StudyTimer-P2.app`；如果使用交付 ZIP，先解压再双击其中的应用。

这是 Apple Silicon 原型，最低部署目标 macOS 13，本机已在 macOS 26.6.2 启动验证。应用不出现在 Dock；悬浮窗右上角“…”与菜单栏计时器图标都能打开演示菜单。窗口丢失时点菜单栏“显示计时窗”，也可再次打开应用。

**时间和历史均为固定示例，不会随等待增加。备注和编辑内容退出后消失，请不要用来保存正式学习记录。** 只记住悬浮窗位置。不要将 P2 的演示结果用于判断真实累计、睡眠或跨天计时；这些属于 P3。

## 3. 本次范围与已知限制
- 已实现原生悬浮窗、菜单栏、拖动/位置记忆、上方卡片及避让、输入框、历史演示及备注编辑、浅色/深色。
- 尚无真实计时、SQLite、自动整小时提醒、真实合并和长期保存，均按后续阶段实施。
- 全屏/Spaces 覆盖、完整拖动体验、中文输入法候选框、点击备注后的真实焦点往返仍需本机人工验收。多显示器、实际 macOS 13 设备未测。
- 仅本地 ad-hoc 签名，未公证；此包用于当前 Mac 测试，不作为公开发行版本。
